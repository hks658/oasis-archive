# 图片与移动端排查（2026-10-08）

## 确认的问题

- 电影搜索、热映、即将上映和剧照原先在浏览器直接请求 TMDB，海报也直接使用外站地址。请求失败不能简单等同于密钥错误，客户端网络也可能无法访问上游。
- IGDB 游戏详情没有请求 `screenshots.image_id`，添加游戏时只保存用户上传的截图，打开详情也不会补取。这能解释有封面但没有游戏画面的情况。
- 游戏封面下载失败会静默退回外链；历史本地图片还依赖部署服务器的 `uploads` 文件存在。
- 页面改为自然滚动后，背景装饰仍保留 600px 宽度和负偏移。手机浏览器测试复现：320px 设备被撑成 562px 布局视口。
- 手机默认播放 1080p 背景视频，同时存在模糊层、入场动画、长廊逐帧几何计算。未对真实手机做帧率采样，不能据此量化卡顿改善幅度。

## 本次修改

- 增加本站 TMDB 代理与固定来源图片网关。API 要求登录；公开图片网关仅允许指定的 TMDB、IGDB 图片路径，禁止跳转，设置超时、类型与大小限制、并发限制及有限缓存。
- 新记录和历史远程图片地址统一走图片网关。加载失败显示明确占位图；客户端不再把电影密钥放入上游请求 URL。
- IGDB 详情请求截图字段；添加/编辑游戏时补取缺失截图，打开历史游戏详情时也可临时补取。已有自定义图片优先。浏览详情不自动改写数据库。
- 手机默认静态背景、海报网格；保留手动播放和长廊切换。减少模糊、入场动画、悬停音频，导航仅在所属分区变化时更新。
- 移除手机端越界背景装饰，约束固定层宽度，调整导航、标签、表单与弹窗。

## 验证与边界

- 通过接口代理测试、筛选测试、移动端图片/布局测试、游戏详情测试、音乐库测试。
- 手机浏览器模拟覆盖 320、390、760px，检查布局宽度、导航和设置弹窗；确认初始加载不请求背景视频。
- 本地预览是样例服务，不连接真实电影或游戏 API；本次接口回归使用模拟上游响应，未验证线上密钥、数据库、服务器出网和真实手机性能。
- 生产需要重新部署前后端，并保证服务器可以访问 TMDB、IGDB、Twitch；图片网关不能解决服务器自身无法访问上游的问题。
- 若历史 `/uploads/…` 文件已经丢失，地址转换不能恢复文件，应检查持久化磁盘或备份。没有 IGDB ID 的手动游戏也无法自动匹配截图。

参考：[IGDB 图片字段](https://api-docs.igdb.com/)、[TMDB 图片地址](https://developer.themoviedb.org/docs/image-basics)。
